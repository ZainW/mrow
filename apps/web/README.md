# @mrow/web

The Mrow website: a handful of prerendered pages built with TanStack Start (React 19, Vite), styled
with plain CSS in Mrow's own palette and fonts. The app window on the home page and the figures on
the other pages are HTML/CSS illustrations filled with made-up data; the site never uses real
screenshots.

## Commands

Run from the repository root (pnpm workspace):

```sh
pnpm install
pnpm --filter @mrow/web dev        # http://localhost:3000
pnpm --filter @mrow/web build      # client + SSR bundles in dist/, every page prerendered
pnpm --filter @mrow/web start      # serve the production build (vite preview; restart it after a build)
pnpm --filter @mrow/web typecheck  # tsc --noEmit
pnpm --filter @mrow/web run deploy # build, then wrangler deploy to https://mrow.wania.app
```

Every page is prerendered by following the links from `/`, so `dist/client` is plain static assets
(`index.html`, `reviewing.html`, `mine.html` and so on, served at `/reviewing`, `/mine`) on
Cloudflare Workers (`wrangler.jsonc`). A new page only needs a link from an existing one. The build
reads the app's version from `apps/desktop/Cargo.toml` (which always equals the latest release)
and shows it beside the downloads; nothing is fetched at run time.

`public/_redirects` gives the short links: `/install` (the install script), `/download/<build>`
(`macos` is the disk image) and `/releases`. They only work on Cloudflare, not under `vite preview`.

## Pages

| Path | What |
|---|---|
| `/` | The pitch, the interactive window, a line on each page, the download |
| `/reviewing` | The four lists, a review as one page with its contents rail, tabs, the two accounts |
| `/mine` | Your own requests by whose move it is, what's left before a merge, stacks, the inbox and notifications |
| `/ask` | The chat with Cursor, Claude, opencode or pi, drafted comments, how each agent is kept to reading |
| `/privacy` | Everything Mrow connects to, and when |
| `/keys` | Every shortcut, from the app's `COMMANDS` table |
| `/download` | The builds, the install command, requirements, updates, building from source |

When the app changes, `apps/desktop/README.md` and the code are the source of truth; `ROADMAP.md`
lists what isn't built, which the site doesn't mention.

## Layout

- `src/routes/__root.tsx`: the document shell, fonts and stylesheet. Each route sets its own title,
  description and canonical address with `seo()` from `src/lib/site.ts`.
- `src/routes/*.tsx`: one file per page.
- `src/components/Layout.tsx`: the header, footer and skip link around every page.
- `src/components/Chapter.tsx`: the page heading, the reading column with margin notes and
  figures, and the shortcut keys (drawn with Mac glyphs, relabelled for Linux visitors by
  `src/lib/keys.ts`, the way the app does it).
- `src/components/Download.tsx`: the download for the visitor's computer (`src/lib/platform.ts`
  works it out after hydration), the download list and the terminals.
- `src/components/AppMock.tsx`, `mockData.ts`: the interactive window and its fictional queue;
  `figures.tsx` builds the page figures from the same pieces.
- `src/styles.css`: tokens from the app's palette (`apps/desktop/src/ui/theme.rs`), light and dark.
- `src/routeTree.gen.ts`: generated by the TanStack Router plugin on `dev`/`build`. It's committed
  so `typecheck` works on a fresh clone; don't edit it by hand.
- `public/fonts`: Inter and Geist Mono, and Mrow Reading, a Latin subset of Charis SIL (the app's
  reading serif) renamed because the SIL Open Font License reserves the name "Charis" for
  unmodified copies. Their licences sit beside them. The app bundles the full faces in
  `apps/desktop/assets/fonts`.

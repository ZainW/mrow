# @mrow/web

The Mrow website: a single page built with TanStack Start (React 19, Vite), styled with plain CSS
in Mrow's own palette and fonts. The app window on the page is an HTML/CSS illustration filled
with made-up data; it never uses real screenshots.

## Commands

Run from the repository root (pnpm workspace):

```sh
pnpm install
pnpm --filter @mrow/web dev        # http://localhost:3000
pnpm --filter @mrow/web build      # client + SSR bundles in dist/
pnpm --filter @mrow/web start      # serve the production build (vite preview)
pnpm --filter @mrow/web typecheck  # tsc --noEmit
```

## Layout

- `src/routes/__root.tsx`: the document shell, meta tags and stylesheet.
- `src/routes/index.tsx`: the page and its sections.
- `src/components/AppMock.tsx`, `mockData.ts`: the interactive window and its fictional queue.
- `src/styles.css`: tokens from the app's palette (`apps/desktop/src/ui/theme.rs`), light and dark.
- `src/routeTree.gen.ts`: generated by the TanStack Router plugin on `dev`/`build`. It's committed
  so `typecheck` works on a fresh clone; don't edit it by hand.
- `public/fonts`: Inter and Geist Mono, with their OFL licences (the app bundles the same faces in `apps/desktop/assets/fonts`).

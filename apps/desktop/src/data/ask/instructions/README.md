# Writing rules for Ask

`technical-writing.md` and `unslop.md` are the `technical-writing` and `unslop` skills from
[pstack](https://github.com/cursor/plugins/tree/main/pstack) (version 0.14.1) by Lauren Tan, under the MIT license in `LICENSE`.
Mrow sends them with the first question of every chat (`context.rs`), so the agent's answers
follow them.

To update them, copy the skills' `SKILL.md` files here without their frontmatter.
